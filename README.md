# 时序 · Windows金融事件日历

朋友公开发行与软件更新通道。程序运行期间可自动联网获取公开金融数据；个人日程、持仓代码、收藏和提醒仅保存在各自电脑。

## 已安装朋友版1.8或1.9

下载本仓库版本发布中的 `Shixu_Friends_Enable_Updates.zip`，完整解压，退出旧时序后运行 `CONNECT_UPDATES.cmd`。它使用已安装的运行环境，下载和验证新版后启用朋友更新通道。已有其他更新通道会保留。

此步骤只需一次。以后启动和运行期间后台检查新版，下载就绪后退出、重新打开时序生效；保留版本历史与回退。

## 新安装

下载版本发布中的 `Shixu_Windows_1.10_Friends.zip`，完整解压后运行 `INSTALL_WINDOWS.cmd`，从桌面“时序”打开。Windows10/11 x64，使用系统Edge。

## 自动获取数据

- 当前日历窗口约每15分钟检查。
- 最近48小时内已到公布时间的宏观事件后台核对；公布后两小时内约每两分钟重试，之后约15分钟检查，每轮最多两项。
- 行情在交易时段约30分钟刷新；财报、FOMC、期权详情点开后按需联网更新。
- 实际宏观公布值优先国家统计局、BLS、BEA、美联储官网。免费财经快讯和RSS补充预期与同口径核对，不依赖金十付费Token。
- 官网正式页、归档、发布列表、RSS为备用入口；同一统计机构的多个入口不算独立统计来源。
- 断网或取数失败保留缓存与原核实时间；退出服务、睡眠或关机时不承诺继续取数。不是全市场无遗漏或交易信号保证。

## 程序更新校验

固定HTTPS地址，RSA-SHA256签名 + SHA256摘要 + 应用文件白名单。无需GitHub账号或Git。签名私钥、私人仓库、账户授权、持仓和个人日程不在本仓库。

当前程序：1.10.0。完整包和接入工具见本仓库 Releases；当前签名清单为 `updates/stable.json`。

Windows原生安装、系统日历导入与响铃仍需实机验收。标准日历文件导入是单次导入，客户端需要确认，后续修改不会自动同步。
