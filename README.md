# 时序 · Windows金融事件日历

朋友公开发行与自动更新通道。每台电脑独立联网获取公开数据；个人日程、持仓代码、收藏与提醒保存在各自电脑。

## 已安装朋友版1.8或1.9

下载[朋友更新接入工具](https://raw.githubusercontent.com/cf377695951/shixu-releases/main/tools/Shixu_Friends_Enable_Updates.zip)，完整解压，退出旧时序后运行`CONNECT_UPDATES.cmd`。它使用已经安装的运行环境，先下载并校验新版，成功后启用朋友更新通道，不要求Git或GitHub账户。已有其他更新通道会保留。

只需接入一次。此后启动和运行期间检查新版，下载就绪后退出、重开生效；版本历史和回退保留。

## 新安装

向维护者索取`Shixu_Windows_1.11_Friends.zip`完整包，完整解压后运行`INSTALL_WINDOWS.cmd`，从桌面“时序”打开。Windows10/11 x64，使用系统Edge。完整包不是本仓库里的小型更新包。

## 新闻快讯

1.11新增三栏：综合快讯、交易所与上新、行情与人物；包含12个方程式公开频道。主快讯实时连接，其他频道在快讯页可见时每分钟检查MCP/RSS。支持最近快讯搜索、币种筛选、单栏阅读、原文和消息出处。

统一北京时间，按时序倒排、多频道同条去重、每栏20条分页、每频道缓存60条。新消息先提示，不强行打断阅读。离开、隐藏窗口或暂停时停止前端接收，正在执行的至多两个列表请求可完成缓存。

内容为自动抓取/翻译的转述；保持来源链接，不当作官方公布数值或交易结论。

## 自动获取金融数据

- 当前日历窗口约15分钟检查；最近48小时宏观事件在到公布时间后后台核对。公布后两小时内约2分钟重试，之后约15分钟，每轮最多2项。
- 公司市值在交易时段约30分钟刷新；财报、FOMC、期权详情按需联网。
- 实际宏观公布值优先国家统计局、BLS、BEA、美联储等官网；免费快讯与RSS辅助预期和同口径核对，无需金十付费Token。
- 同一官网不同入口不算独立统计验证。断网或失败保留缓存和原核实时间；退出服务、睡眠、关机时不继续取数。

## 更新安全

固定HTTPS地址，RSA-SHA256签名、SHA256摘要和应用文件白名单。签名私钥、私人仓库凭据、持仓和个人日程不在本仓库。当前1.11.0；签名清单为`updates/stable.json`，旧版本文件保留。

升级与回退、实际公开接口取数、浏览器界面已验收；Windows原生安装、响铃与系统日历导入需实机验收。.ics导入需要客户端确认，后续修改不自动同步。
